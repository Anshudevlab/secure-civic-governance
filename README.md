# 🏛️ Secure Civic Governance

**A secure and transparent digital platform for citizen grievance management and efficient civic services.**

## 📌 About the Project

Secure Civic Governance is a web-based application designed to improve communication between citizens and government departments. It allows citizens to submit civic complaints and track their progress using a reference number, while administrators can manage grievances and update their status.

The project aims to promote transparency, accountability, and accessible public services through technology.

## 🎯 Problem Statement

Traditional grievance management systems can make it difficult for citizens to track complaints, receive updates, and know whether their issues have been resolved.

## 💡 Our Solution

This platform provides a centralized digital system where citizens can submit grievances, track their status, and receive clearer information about their progress. Administrators can review complaints and update their status through a dashboard.

## ✨ Key Features

- 📝 Submit civic grievances online
- 🔎 Track complaints using a reference number
- 📊 Admin dashboard to manage grievances
- 🔄 Update grievance status
- 📥 Export grievance records to CSV
- 🔐 Admin login and session-based access control
- 💾 Store grievance data using SQLite
- 🔄 Maintain status updates after refreshing the page

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### Prerequisites

- Python 3
- Git
- A web browser

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Anshudevlab/secure-civic-governance.git
   ```

2. Open the project directory:

   ```bash
   cd secure-civic-governance
   ```

3. Install the required Python packages:

   ```bash
   python -m pip install flask
   ```

4. Configure the required environment variables for the Flask secret key and administrator credentials according to the application's configuration.

5. Start the application using your configured local startup script or run the Flask application with the required environment variables set.

6. Open your browser and visit:

   ```text
   http://127.0.0.1:8080/
   ```

**Note:** Keep administrator credentials and secret keys private. Do not upload your local database or files containing credentials.
